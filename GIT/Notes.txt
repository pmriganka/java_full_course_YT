
PROBLEM:

Performed a commit on the wrong branch

SOLUTION:

1. Go to the wrong branch
2. Unod the commit but keep the file changes using

    git reset HEAD~1 (This removes the commit and leaves the files modified in your working directory.)

3. Switch to the correct branch
4. If you cannot switch branches

    git checkout -b <new-branch-name>git stash push -u -m "Move changes to fornax_upgrade_downgrade_second_part"
    (-u includes the untracked files (.JSON, output.log, etc.)

5. Now switch to the original branch 
6. Apply the stash using

    git stash pop

7. if you do not get the modified files after stash pop this means the files are already committed
8 Check the aboce using

    git diff ( If nothing shown it mean your working directory matches the HEAD)
    git reflog -10 ( Look for the commit you reset away)
    git log --oneline --decorate -10
